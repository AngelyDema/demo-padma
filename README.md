# Proyecto: PADMA

Padma es un proyecto personal web enfocada en la gestión de tareas y hábitos.

## Estado actual:
Padma actualmente es una web desarrollada en Springboot, con base de datos postgrest, funciones incompletas (Restablecer contraseña, inicio de sesión con google) y vistas hechas con la librería  thymeleaf.

## Plan de reengineering: 

Este se hace con el objetivo de aplicar buenas prácticas de desarrollo, análisis y diseño y tomar desiciones arquitectónicas coherentes para el proyecto. 

Se realizará una reingeniería del sistema, compuesta por:

* (1) ingeniería inversa para el análisis y documentación de la arquitectura actual
* (2) reestructuración del código
* (3) ingeniería directa para la contenerización, el despliegue y la incorporación de nuevas funcionalidades.

Este documento será una vista general del proceso, más detalles se verán en la carpeta "docs"
