# Estado Actual de proyecto PADMA: 

Padma es una web creada como proyecto académico para la creación y seguimiento de hábitos y funciones de to-do list. La cual actualmente cuenta con lo siguiente:

## Stack tecnológico: 
* Springboot como framework de desarrollo
* Vistas desarrolladas con la librería thymeleaf
* PostgrestSQL desplegada en railway 

## Documentación existente: 
* Documento de levantamiento de requerimientos
* Diagrama de clases

## Funciones principales: 
* CRUD de lista to-do y to-dos
* CRUD de áreas de hábitos y hábitos
* Inicio  de sesión por credenciales
* Recuperación de contraseña (incompleta)
* Crear cuenta
* Inicio de sesión por google (Incompleto)
* Marcar tarea como hecha
* Marcar hábito como hecho
